Adherence

Measure data availability for wearable physiological streams.

The module exposes adherence for heart rate, beat-to-beat intervals (BBI), and sleep summaries. Each stream has a different native availability model:

  • heart rate measures the fraction of physical time represented by occupied one-minute bins;

  • BBI measures the positive interval duration represented in a window; and

  • sleep measures the presence of a usable main-sleep summary for each local calendar date.

Scalar resolutions report that native coverage directly. Resolution chains instead turn coverage at each non-final level into a valid/invalid child and report the fraction of expected children that remain valid at the final level. Unsupported streams and inapplicable metric/resolution combinations are represented by missing values, while supported streams with no observations have zero adherence.

pywearable.adherence.get_adherence(loader, metric=None, user_id='all', start_date=None, end_date=None, resolution='daily', time_reference='auto', min_coverage=None, loader_kwargs=None, cycle_kwargs=None, check_sleep_validation=True)

Return final data-availability adherence over [start_date, end_date).

Heart-rate adherence is the fraction of physical time represented by one-minute bins containing at least one positive sample. BBI adherence is positive BBI duration divided by expected physical duration. Sleep adherence is usable main-sleep-summary presence over expected local dates.

A scalar resolution reports raw coverage directly. A resolution sequence qualifies children at every non-final level and reports final valid children / expected children coverage. Children have equal weight, irrespective of their physical duration. Sleep enters a hierarchy at its native daily grain, so lower fixed resolutions are ignored rather than populated with artificial observations.

Parameters:

  • loader (BaseLoader) – Loader providing the requested streams and user identifiers.

  • metric (str | list | tuple | None) – One metric name, a sequence of names, or None for all of 'heart_rate', 'sleep', and 'bbi'. Output columns follow the requested order and are named <metric>_adherence.

  • user_id (str | list | None) – One user, a sequence of users, 'all', or None. None is an alias for 'all'.

  • start_date – Required half-open bounds, normalized to the clock selected by time_reference. Sleep calendar bounds are always local.

  • end_date – Required half-open bounds, normalized to the clock selected by time_reference. Sleep calendar bounds are always local.

  • resolution (str | Timedelta | list | tuple) – A fixed resolution, calendar resolution, cycle type, or an ordered resolution chain accepted by the shared resolution normalization. 'nightly' is an alias for cycle_night for physical streams and for date-labelled nightly sleep-summary availability for sleep.

  • time_reference (str) – 'auto', 'local', or 'utc'. 'auto' selects UTC for fixed physical windows and local time for calendar or cycle windows. All requested physical metrics must support the selected clock. UTC cannot represent sleep calendar adherence.

  • min_coverage – Optional number or sequence with one entry per requested resolution. On non-final levels, a child qualifies when measured coverage is at least this threshold. None qualifies any child with positive coverage. The final entry is not applied because final coverage is the returned value. Consequently, this argument has no filtering effect for a scalar resolution.

  • loader_kwargs (dict | None) – Optional mapping keyed by metric name. Each value is forwarded to that metric’s loader method. Heart-rate time_col is controlled by time_reference and sleep drop_duplicates is controlled here, so callers may not override them.

  • cycle_kwargs (dict | None) – Optional keyword arguments forwarded to pywearable.cycle.get_intervals().

  • check_sleep_validation (bool) – If true, sleep-summary rows labelled MANUAL or AUTO_MANUAL in the canonical validation column do not count as observed nights.

Returns:

Final adherence values indexed by (user_id, time). The time index is named utc_time or local_time for fixed windows and calendar_date for calendar or cycle outputs. Values lie in [0, 1]; missing values indicate an unsupported stream or an inapplicable metric/resolution combination.

Return type:

pandas.DataFrame

Raises:

ValueError – If bounds, metric names, resolutions, thresholds, clocks, or forwarded keyword structures are invalid.

Notes

resolution='daily' measures raw coverage across each day. In contrast, resolution=['5min', 'daily'] measures the fraction of five-minute children that satisfy the primary threshold. These quantities coincide only under particular sampling patterns.

Examples

Direct five-minute coverage for heart rate and BBI:

get_adherence(
    loader,
    metric=['heart_rate', 'bbi'],
    user_id='participant-01',
    start_date='2024-01-01',
    end_date='2024-01-02',
    resolution='5min',
)

Fraction of qualifying five-minute heart-rate windows in each night:

get_adherence(
    loader,
    metric='heart_rate',
    start_date='2024-01-01',
    end_date='2024-02-01',
    resolution=['5min', cycle.CYCLE_NIGHT],
    min_coverage=[0.8, None],
)
pywearable.adherence.get_daily_wearing_time(loader, user_id, start_date, end_date, ceil_to_24=False)

Return daily hours represented by one-minute heart-rate occupancy.

Each daily adherence fraction is multiplied by the exact requested local-day duration, so partial first and last days remain partial.

Parameters:

  • loader (BaseLoader) – Loader providing timestamped heart-rate samples.

  • user_id (str) – One user identifier.

  • start_date (Timestamp) – Required half-open local-time bounds.

  • end_date (Timestamp) – Required half-open local-time bounds.

  • ceil_to_24 (bool) – If true, clip reported daily hours at 24. Adherence is already capped at one, so this only preserves the historical option.

Returns:

Local-date-indexed hours named 'daily-hr'.

Return type:

pandas.Series
