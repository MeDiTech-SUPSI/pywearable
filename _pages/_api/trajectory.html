Trajectory processing

Analysis utilities for canonical wearable feature trajectories.

The functions in this module operate on the (user_id, time) DataFrames returned by pywearable feature modules. Imputation is explicit, leaves coverage unchanged, and records which values it fills. Trend estimates are computed independently for each participant and use historical observations only by default.

pywearable.trajectory.aggregate_trajectory_by_weekday(trajectory, features=None, *, aggregation='mean', include_imputed=False, temporal_features=None)

Aggregate repeated calendar weekdays within each participant.

This operation is intentionally separate from resolution hierarchies: Mondays across different weeks are a descriptive group, not one chronological parent window.

Parameters:

  • trajectory (DataFrame) – Canonical (user_id, time) trajectory with feature coverage columns. Daily, nightly, cycle, and subdaily trajectories are all accepted.

  • features (str | Sequence[str] | None) – Feature name or names. By default, every value column paired with a __coverage column is selected.

  • aggregation (str) – "mean", "median", "min", "max", "std", or a percentile such as "p90". Clock features use circular operations.

  • include_imputed (bool) – Include values marked by <feature>__is_imputed. They are excluded by default.

  • temporal_features (str | Sequence[str] | None) – Additional selected columns to interpret as clock-valued features.

Returns:

One row for every participant and Monday-through-Sunday label. Each feature is accompanied by __support and mean input __coverage.

Return type:

pandas.DataFrame

pywearable.trajectory.compute_trajectory_trend(trajectory, features=None, *, baseline_method='ma', baseline_window=7, min_periods_baseline=3, normal_range_method='ma', normal_range_window=30, min_periods_normal_range=20, std_multiplier=1.0, include_current=False, include_imputed=False, temporal_features=None)

Add participant-specific historical baselines and normal ranges.

Parameters:

  • trajectory (DataFrame) – Canonical (user_id, time) trajectory DataFrame. Every selected feature must have a matching <feature>__coverage column.

  • features (str | Sequence[str] | None) – Feature name or names to analyze. If omitted, all feature/coverage column pairs are selected.

  • baseline_method (str) – Independently selected historical estimators: "ma", "ema", or "cumulative_mean". The baseline describes the expected value; the normal-range method independently determines its center and standard deviation.

  • normal_range_method (str) – Independently selected historical estimators: "ma", "ema", or "cumulative_mean". The baseline describes the expected value; the normal-range method independently determines its center and standard deviation.

  • baseline_window – For "ma", either a number of preceding rows or an elapsed-time window. For "ema", the exponential span. Ignored by cumulative means.

  • normal_range_window – For "ma", either a number of preceding rows or an elapsed-time window. For "ema", the exponential span. Ignored by cumulative means.

  • min_periods_baseline (int) – Minimum observed values required for the corresponding estimate.

  • min_periods_normal_range (int) – Minimum observed values required for the corresponding estimate.

  • std_multiplier (float) – Non-negative number of standard deviations below and above the normal center used for range bounds.

  • include_current (bool) – Include the value on the current row in historical estimates. The default False makes every estimate strictly backward-looking.

  • include_imputed (bool) – Include values marked by <feature>__is_imputed as estimator input. They are excluded by default.

  • temporal_features (str | Sequence[str] | None) – Additional selected features to interpret as clock times. Canonical temporal features and datetime-like columns are detected automatically.

Returns:

A copy of the input with these columns for every selected feature: __trend_baseline, __trend_normal_center, __trend_normal_std, __trend_normal_lower, __trend_normal_upper, __trend_deviation, and support counts for the baseline and normal range.

Return type:

pandas.DataFrame

Notes

Participants are always analyzed independently. Numeric deviations and standard deviations retain the feature’s units. Clock-valued centers and bounds remain clock values; their deviation and circular standard deviation are expressed in minutes.

pywearable.trajectory.impute_trajectory(trajectory, features=None, *, method='ma', window=7, min_periods=3, fallback=None, temporal_features=None)

Fill missing values in one or more canonical feature trajectories.

Parameters:

  • trajectory (DataFrame) – DataFrame indexed by (user_id, time). A timezone index level is optional. Every selected feature must have a matching <feature>__coverage column.

  • features (str | Sequence[str] | None) – Feature name or names to impute. If omitted, all feature/coverage column pairs are selected.

  • method (str) – Estimator used for missing values. Historical choices are "ma" (trailing moving mean), "rolling_median", "ema", and "cumulative_mean". Retrospective choices are "user_mean", "user_median", "population_mean", and "population_median".

  • window – For "ma" and "rolling_median", either the number of preceding rows or an elapsed-time window such as "30D". For "ema", the exponential span. Ignored by the other methods.

  • min_periods (int) – Minimum number of observed values required by a historical estimator.

  • fallback (str | None) – Optional "user_mean", "user_median", "population_mean", or "population_median" used when a historical estimator has insufficient support. No fallback is applied by default.

  • temporal_features (str | Sequence[str] | None) – Additional selected features to interpret as clock times. Canonical sleep times, peak-activity start times, and datetime-like columns are recognized automatically.

Returns:

A copy with fillable values replaced and one boolean <feature>__is_imputed column per selected feature. Input rows and coverage columns are unchanged.

Return type:

pandas.DataFrame

Notes

Historical estimates are participant-specific, use observations preceding the missing row, and never use values filled by this or an earlier call. Full-user methods compute the mean or median from all observed values for that participant in the complete supplied trajectory. Population methods compute one mean or median from all observed values across every participant and date in the supplied trajectory, then use it for every participant; no loader or external cohort data is consulted. Clock features are aggregated by time of day and restored on the missing row’s relevant calendar date.
