Provider-native features

Extraction of explicitly provider-native wearable features.

Feature names retain their provider prefix because similarly named vendor scores are not assumed to measure the same construct. Timestamped streams can be windowed or assigned to cycles; native daily and nightly features can only remain at their native grain or be aggregated upward.

pywearable.provider_features.get_available_provider_features(loader)

Return provider-feature names implemented by loader.

Parameters:

loader (BaseLoader) – Loader whose provider-native feature support should be inspected. Additional names require a matching entry in the loader’s provider_feature_definitions mapping.

Returns:

Sorted feature names accepted by get_provider_features().

Return type:

list of str

pywearable.provider_features.get_provider_features(loader, feature, statistic=None, user_id='all', start_date=None, end_date=None, resolution=None, loader_kwargs=None, time_reference='auto', aggregation=None, min_coverage=None, cycle_kwargs=None, min_valid_children=None)

Extract provider-native features without equating vendors’ metrics.

Parameters:

  • loader (BaseLoader) – Loader declaring the requested feature in provider_features and returning canonical rows from load_provider_feature. Custom names must also be described by provider_feature_definitions.

  • feature (str or sequence of str) – Names reported by get_available_provider_features(). Features in one call must share a native grain. This argument is required because a loader can expose unrelated sample, daily, nightly, numeric, and categorical provider features that cannot form one implicit result.

  • statistic (str, sequence of str, or None) – Primary reduction(s) for timestamped streams. None means mean. Native summaries reject this argument because they are already values.

  • user_id (str, sequence of str, or None) – Participant selection; "all" and None select every loader user.

  • start_date (date-like or None) – Half-open sample or native-label range, [start_date, end_date).

  • end_date (date-like or None) – Half-open sample or native-label range, [start_date, end_date).

  • resolution (str, pandas.Timedelta, sequence, or None) – Primary window or increasing hierarchy. None selects daily windows for samples and the native grain for summaries. Native summaries may only remain native or aggregate to week, month, or year.

  • loader_kwargs (dict or None) – Extra arguments for the loader or cycle interval extraction.

  • cycle_kwargs (dict or None) – Extra arguments for the loader or cycle interval extraction.

  • time_reference ({"auto", "local", "utc"}) – Clock used by timestamped streams. Native summaries use local labels.

  • aggregation (str, sequence, or None) – Parent-level operation(s); valid only for a hierarchy.

  • min_coverage (float, sequence, or None) – Minimum valid sample/day/child fraction at each requested level.

  • min_valid_children (int, sequence, or None) – Minimum valid children at each parent level.

Returns:

Indexed by participant and time/date, with one __coverage column per output feature. Hierarchical column names encode resolutions and operations.

Return type:

pandas.DataFrame
