Activity

Use pywearable.activity.get_activity_statistics() as the canonical entry point. The fixed-resolution helpers below specialize its defaults and share its parameter semantics.

Step-count volume and peak-hour timing across temporal resolutions.

pywearable.activity.get_activity_statistic(loader, statistic, **kwargs)

Return one named activity feature; see get_activity_statistics().

Parameters:

  • loader (BaseLoader)

  • statistic (str)

pywearable.activity.get_activity_statistics(loader, statistic=None, user_id='all', start_date=None, end_date=None, resolution='daily', loader_kwargs=None, time_reference='auto', aggregation=None, min_coverage=None, cycle_kwargs=None, min_valid_children=None)

Return step-volume and timing features at one or more resolutions.

Parameters:

  • loader (BaseLoader) – Loader exposing timestamped incremental step intervals or calendar-day step totals through the shared activity schema.

  • statistic (str | list | tuple | None) – One feature name or a sequence. Timestamped sources support activity_steps, activity_peak_60min_steps, and activity_peak_60min_start. Daily-summary sources support only activity_steps. Omitting the argument selects every supported feature for that source.

  • user_id (str | list | tuple | None) – One participant, several participants, or "all"/None.

  • start_date – Inclusive/exclusive bounds. Calendar resolutions use participant-local dates; fixed resolutions use the clock selected by time_reference.

  • end_date – Inclusive/exclusive bounds. Calendar resolutions use participant-local dates; fixed resolutions use the clock selected by time_reference.

  • resolution (str | Timedelta | list | tuple) – A fixed duration, calendar or sleep-cycle name, or an increasing hierarchy. "1h" returns hourly step totals. Calendar-day sources start at daily resolution. Weekly, monthly, and yearly scalar requests are shorthand for daily-to-parent hierarchies.

  • loader_kwargs (dict | None) – Extra keyword arguments passed only to the loader method.

  • time_reference (str) – "auto", "local", or "utc". Calendar and cycle windows default to local time; fixed windows prefer UTC when available.

  • aggregation – Built-in names or named Series-to-scalar callables at each upper hierarchy level. Activity defaults are feature-specific: steps are summed, while peak values and peak clock times are averaged. Thus resolution="weekly" returns total weekly steps, whereas resolution=["daily", "weekly"], aggregation="mean" returns mean valid daily steps.

  • min_coverage – Optional threshold per level. For timestamped primary windows, coverage is the union of one-minute intervals containing valid heart rate and native intervals containing positive steps, divided by the requested window duration. For native daily summaries it is value availability. At upper levels it is the fraction of valid child features. Values below threshold become missing while measured coverage remains in <feature>__coverage columns.

  • cycle_kwargs (dict | None) – Extra arguments passed to pywearable.cycle.get_intervals().

  • min_valid_children – Optional minimum number of valid children at each upper level.

Returns:

A (user_id, time) trajectory containing every requested feature and its __coverage column. An interval contributes when it is fully contained in the requested window. Peak 60-minute values require one completely observed contiguous hour inside the requested window. Fixed-duration output also contains the alternate clock and the timezone UTC offset for each window.

Return type:

pandas.DataFrame
