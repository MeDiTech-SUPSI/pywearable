Loaders

Portable interface

class pywearable.loader.BaseLoader

Portable interface for project- and provider-specific data loaders.

Loader authors translate source fields into the canonical schemas defined in pywearable.schema. Required streams are implemented by the abstract methods below. Optional streams may retain the default typed empty result, while capability attributes describe which clocks and source grains are available to the domain modules.

Date bounds are half-open: [start_date, end_date). Implementations should return an empty DataFrame with the canonical columns when a supported stream has no rows in the requested interval.

class pywearable.loader.LabfrontLoader(data_paths, reindex_files=False, sleep_stage_on_conflict='drop_night')

Loader for Labfront data.

This is the main object for loading and analyzing data collected with Labfront.

Parameters:

  • data_paths (str, pathlib.Path, or list) – Path or paths to folders containing Labfront data.

  • reindex_files (bool, optional) – Rebuild the local Labfront file index, by default False.

  • sleep_stage_on_conflict ({"drop_night", "raise", "last"}, optional) – How to handle repeated sleep-stage snapshots that cannot be resolved against a sleep summary. "drop_night" keeps the summary but omits the ambiguous stage rows, "raise" stops loading, and "last" uses the last snapshot in Labfront file-index order. By default "drop_night".

class pywearable.loader.OuraLoader(data_dir)

Load a local directory of participant-level Oura API v2 responses.

The root directory must contain one directory per participant. Each participant directory contains one directory per Oura endpoint, and each endpoint directory contains one or more JSON response pages:

data_dir/
    participant_id/
        sleep/
            data.json
            data_2.json
        daily_sleep/
            data.json
        heartrate/
            data.json

Every JSON file must contain an object with a data list, matching the Oura API v2 response envelope. Pagination files are merged in filename order. Identical repeated records are collapsed; records with the same provider identifier but different content raise an error rather than being overwritten silently. Missing endpoint directories produce empty tables.

Daily and nightly loaders use Oura’s day as calendar_date. Subdaily loaders expose offset-aware instants as timezone-naive UTC in utc_time. Sleep loaders additionally expose participant-local clock times derived from the offsets included in each sleep record.

Load heart-rate samples in the shared heart-rate schema.

Implementations return utc_time, local_time, timezone (a UTC offset as pandas.Timedelta), and heart_rate. A loader can advertise unavailable clocks through heart_rate_time_columns; their canonical columns are retained but contain missing values. Bounds are inclusive/exclusive and are applied to time_col. Direct calls default to local time. Feature extraction uses UTC for subdaily windows and local time for calendar windows unless explicitly overridden.
