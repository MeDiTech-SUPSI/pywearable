HRV

Use pywearable.hrv.get_hrv_statistics() as the canonical entry point. The convenience getters below select a common feature or resolution and refer to it for shared parameter and coverage semantics.

Raw-BBI extraction supports overlapping primary windows through window_step and configurable sleep-stage exclusion through sleep_stages_to_remove. The built-in and NeuroKit backends expose separate default feature registries; explicit statistic selections return only the requested features.

Only finite, positive BBI values contribute to extraction. Repeated observations with the same physical timestamp and BBI value are counted once.

Heart-rate-variability features from BBI or provider estimates.

pywearable.hrv.get_hrv_statistics(loader, statistic=None, user_id='all', start_date=None, end_date=None, resolution='day', loader_kwargs=None, time_reference='auto', aggregation=None, min_coverage=None, cycle_kwargs=None, min_valid_children=None, backend='pywearable', window_step=None, sleep_stages_to_remove=('awake', 'unmeasurable'))

Return HRV features at five minutes or along a resolution hierarchy.

Raw-BBI loaders calculate five-minute features, with optional overlap. Provider loaders use their native five-minute estimates and leave unsupported statistics missing. A scalar calendar or cycle resolution is shorthand for a five-minute-to-parent hierarchy. Source selection is fixed by the loader; missing provider values are never filled from a different HRV source.

min_coverage supplies one threshold per level. At the primary raw-BBI level, coverage is represented BBI duration divided by window duration. Provider coverage is used when available; an explicit primary threshold rejects provider samples whose coverage is unavailable. Higher-level coverage is the fraction of valid child features.

Parameters:

  • loader (BaseLoader) – Loader exposing raw beat-to-beat intervals or provider-computed HRV samples.

  • statistic (str | list | tuple | None) – One HRV feature name, a sequence of names, or None for every feature registered for the selected backend.

  • user_id (str | list | None) – One participant, several participants, or "all"/None.

  • start_date – Half-open analysis bounds. For cycle resolutions, the bounds select cycle calendar labels and selected cycles are not clipped.

  • end_date – Half-open analysis bounds. For cycle resolutions, the bounds select cycle calendar labels and selected cycles are not clipped.

  • resolution (str | Timedelta | list | tuple) – A five-minute, calendar, or sleep-cycle resolution, or an increasing hierarchy. Calendar and cycle shorthand requests automatically begin from the native five-minute HRV grain.

  • loader_kwargs (dict | None) – Extra keyword arguments passed to the loader’s HRV method.

  • time_reference (str) – "auto", "local", or "utc" for fixed windows. Calendar and sleep-cycle parents require participant-local time.

  • aggregation – Built-in names or named Series-to-scalar callables for each parent level, optionally branching. Requires a hierarchy.

  • min_coverage – Optional minimum coverage at each requested level. A scalar applies to every level; a sequence supplies one value per resolution.

  • cycle_kwargs (dict | None) – Extra arguments passed to pywearable.cycle.get_intervals().

  • min_valid_children – Optional minimum number of valid child windows at each parent level. In sequence form, the primary entry must be None.

  • backend (Literal['pywearable', 'neurokit']) – "pywearable" for the built-in raw-BBI calculation or "neurokit" for the optional NeuroKit backend. Both backends retain the observed BBI time axis when processing irregular intervals.

  • window_step (str | Timedelta | None) – Displacement between primary five-minute windows. None preserves non-overlapping windows; a shorter duration creates overlapping raw-BBI windows. Sleep-cycle overlap retains only fully contained windows. Provider-computed HRV cannot be re-windowed.

  • sleep_stages_to_remove (str | list | tuple | None) – Sleep stages excluded from sleep-cycle extraction. By default, awake and unmeasurable are removed. None or an empty sequence disables stage filtering.

Returns:

Fixed-duration output keeps the selected clock in the index and adds the alternate clock and timezone UTC offset as columns. A (user_id, time) trajectory containing each requested feature and its __coverage column. Hierarchical names preserve the complete calculation path.

Return type:

pandas.DataFrame

Examples

Five-minute RMSSD:

get_hrv_statistics(loader, statistic="hrv_rmssd", resolution="5min")

Nightly RMSSD followed by monthly mean and p90:

get_hrv_statistics(
    loader,
    statistic="hrv_rmssd",
    resolution=["5min", "cycle_night", "monthly"],
    aggregation=[["mean"], ["mean", "p90"]],
    min_coverage=[0.7, 0.5, 0.8],
    min_valid_children=[None, 3, 10],
)
