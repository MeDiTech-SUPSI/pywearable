Sleep

Use pywearable.sleep.get_sleep_statistics() as the canonical entry point. Named and calendar-resolution getters below specialize that function; their signatures show the fixed feature or resolution, while shared bounds, coverage, and hierarchy semantics are documented on the canonical function.

This module contains all the functions related to analysis of sleep data.

pywearable.sleep.get_sleep_statistics(loader, statistic=None, user_id='all', start_date=None, end_date=None, resolution='nightly', loader_kwargs=None, chronotype=None, aggregation=None, min_coverage=None, min_valid_children=None)

Return main-sleep features at night level or along a hierarchy.

Requesting "weekly", "monthly", or "yearly" as a single resolution is shorthand for a nightly hierarchy ending at that calendar resolution. Resolution sequences explicitly define each increasingly larger level, for example ["nightly", "weekly", "monthly"]. Upper levels give each valid child row equal weight and return immediate valid / expected coverage in [0, 1]. Nightly coverage is binary feature availability: 1 when that feature is present and 0 when it is missing on an expected calendar date. This is feature-specific: a sleep summary alone does not produce coverage 1 for every metric. For example, CPD that cannot be computed without the preceding night’s data has coverage 0. At upper levels, coverage is the fraction of expected nights containing a valid feature.

aggregation selects the operation or branching operations at each upper level; None uses the shared standard operations. A min_coverage sequence supplies one threshold per resolution. When both the calendar resolution and threshold are given as single values, the threshold applies to that calendar level. min_valid_children independently requires an absolute number of valid child windows at each upper level; a single value applies to every upper level, while a sequence uses None for the nightly level.

Parameters:

  • loader (BaseLoader) – Loader exposing canonical main-sleep summaries and, where required by the selected features, sleep-stage intervals.

  • statistic (str | list | tuple | None) – One sleep feature name, a sequence of names, or None for all registered sleep features.

  • user_id (str | list | None) – One participant, several participants, or "all"/None.

  • start_date (datetime | date | str | None) – Half-open range of participant-local sleep calendar labels. Selected nights retain their complete physical intervals across midnight.

  • end_date (datetime | date | str | None) – Half-open range of participant-local sleep calendar labels. Selected nights retain their complete physical intervals across midnight.

  • resolution (str | list | tuple) – "nightly"/"daily", a calendar parent, or an increasing hierarchy beginning with the nightly grain.

  • loader_kwargs (dict | None) – Extra keyword arguments passed to the loader’s sleep methods.

  • chronotype (dict | None) – Optional participant-to-chronotype mapping used by composite phase deviation features.

  • aggregation – Operation or branching operations for each parent level. It is valid only when the request contains a parent resolution.

  • min_coverage – Optional minimum feature coverage at each requested level. When the calendar resolution and threshold are each given as one value, the threshold applies to the calendar parent.

  • min_valid_children – Optional minimum number of valid nightly or intermediate child rows at each parent level.

Returns:

A (user_id, calendar_date) trajectory containing each requested feature and its __coverage column. Hierarchical names preserve the complete calculation path.

Return type:

pandas.DataFrame

Return a regular local-time sleep/wake trajectory.

Wake between consecutive main-sleep sessions is inferred. Recorded sessions interrupt that inference and are classified only where stage data are available. Missing nights, unmeasurable stages, and other gaps remain missing. Non-main sessions are included when the loader exposes them and include_naps is true.
