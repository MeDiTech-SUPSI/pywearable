pywearable.schema.prepare_activity_samples(frame)

Normalize canonical timestamped incremental step intervals.

Each row represents a half-open interval beginning at utc_time or local_time with duration_in_ms and an incremental activity_steps count. Zero-step intervals are valid observations. Exact duplicates are coalesced; conflicting duplicate intervals retain one row with a missing step count.

Return type:

DataFrame

pywearable.schema.prepare_heart_rate_samples(frame)

Validate and normalize canonical timestamped heart-rate samples.

Loaders must translate vendor columns before calling this function. Duplicate and conflicting exports are preserved so each loader can apply its documented reconciliation policy.

Return type:

DataFrame

pywearable.schema.prepare_provider_feature_samples(frame, feature)

Validate canonical timestamped samples for one provider-native feature.

Loaders must translate vendor columns before calling this function. Exact timestamp duplicates collapse to one row. If repeated rows disagree about the feature value, one row is retained with that value missing; downstream coverage therefore records the conflict without selecting an arbitrary export revision.

Parameters:

feature (str)

Return type:

DataFrame

pywearable.schema.prepare_provider_feature_summary(frame, feature, *, numeric=True)

Validate one canonical provider feature at native daily grain.

The input must already use calendar_date and the canonical feature name. The loader must resolve exact export duplicates or revisions first; this validator rejects any remaining duplicate date rather than choosing one provider value silently.

Parameters:

  • feature (str)

  • numeric (bool)

Return type:

DataFrame
