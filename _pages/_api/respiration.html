Respiration

Use pywearable.respiration.get_respiration_statistics() as the canonical entry point. The convenience getters below select a feature or native resolution and share its parameter semantics.

Respiratory-rate and oxygen-saturation feature extraction.

pywearable.respiration.get_awake_respiration_statistics(loader, **kwargs)

Return one raw-sample feature row per awake cycle.

Pass feature, user, date, and coverage options via kwargs as in get_respiration_statistics(). Provider-only nightly summaries cannot produce awake cycles. Output is indexed by user and cycle date.

Parameters:

loader (BaseLoader)

pywearable.respiration.get_five_minute_respiration_statistics(loader, **kwargs)

Return raw-sample features in non-overlapping five-minute windows.

Pass feature, user, date, and coverage options via kwargs as in get_respiration_statistics(). Provider-only nightly summaries cannot produce this resolution. Output is a DataFrame by user and time.

Parameters:

loader (BaseLoader)

pywearable.respiration.get_respiration_statistic(loader, statistic, **kwargs)

Return one named respiratory-rate or SpO2 feature.

loader and kwargs have the same meaning as in get_respiration_statistics(). A direct single-feature request always includes the feature’s coverage column.

Parameters:

  • loader (BaseLoader)

  • statistic (str)

pywearable.respiration.get_respiration_statistics(loader, statistic=None, user_id='all', start_date=None, end_date=None, resolution='cycle_night', loader_kwargs=None, time_reference='auto', aggregation=None, min_coverage=None, cycle_kwargs=None, min_valid_children=None, spo2_threshold=90.0)

Extract respiratory-rate and SpO2 features at the requested resolution.

Parameters:

  • loader (BaseLoader) – Supplies canonical samples or provider-native nightly summaries.

  • statistic (str, sequence of str, or None) – Feature name(s); None selects all core metrics. Percentiles such as spo2_p20 and respiratory_rate_p75 are also accepted.

  • user_id (str, sequence of str, or None) – Participant(s); "all" or None selects every loader user.

  • start_date (date-like or None) – Half-open time or night-label range, [start_date, end_date).

  • end_date (date-like or None) – Half-open time or night-label range, [start_date, end_date).

  • resolution (str, pandas.Timedelta, or sequence) – Primary window or ascending hierarchy, for example "5min" or ["5min", "cycle_night"]. Provider summaries support only their native "cycle_night" grain and larger calendar periods.

  • loader_kwargs (dict or None) – Extra keyword arguments passed to the corresponding loader or cycle interval function.

  • cycle_kwargs (dict or None) – Extra keyword arguments passed to the corresponding loader or cycle interval function.

  • time_reference ({"auto", "local", "utc"}) – Clock for raw samples; "auto" uses local time for calendar/cycle windows and UTC for fixed windows when available. Provider summaries are date-labelled and do not support UTC selection.

  • aggregation (str, collections.abc.Callable, sequence, or None) – Built-in names or named Series-to-scalar callables at each parent level; requires a hierarchy. None uses the shared standard aggregations.

  • min_coverage (float, sequence, or None) – Minimum valid fraction at each level. Raw primary coverage estimates observed versus expected samples; provider coverage is used only when supplied. Unknown primary coverage fails an explicit threshold.

  • min_valid_children (int, sequence, or None) – Minimum valid child windows at each parent level.

  • spo2_threshold (float) – SpO2 percentage threshold for below-threshold fraction and duration; the comparison is strictly below this value.

Returns:

Indexed by (user_id, utc_time/local_time/calendar_date) with one __coverage column per requested feature. Hierarchical column names include each resolution and aggregation. Unsupported provider-summary features are missing, never inferred from summary means. Below-threshold duration is in seconds. Fixed-duration output also contains the alternate clock and the timezone UTC offset.

Return type:

pandas.DataFrame

pywearable.respiration.get_night_respiration_statistics(loader, **kwargs)

Return one feature row per main-sleep night.

Raw samples are grouped by sleep-cycle intervals; provider summaries are returned at their native night labels. kwargs are forwarded to get_respiration_statistics(); output is indexed by user and night.

Parameters:

loader (BaseLoader)
