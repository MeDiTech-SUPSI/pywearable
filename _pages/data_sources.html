Data sources

Loaders translate provider-specific exports into the canonical schemas used by the analysis modules. Code using activity, sleep, heart_rate, and the other domains therefore does not need to know the original field names.

The first-release public loaders are:

Supported loaders

Dataset

Loader

Input

Labfront

pywearable.loader.LabfrontLoader

Extracted Labfront study exports

LifeSnaps

pywearable.loader.LifeSnapsParquetLoader

Locally converted Parquet version of the LifeSnaps dataset

Oura

pywearable.loader.OuraLoader

Participant directories containing Oura API v2 JSON responses

Tesserae

pywearable.loader.TesseraeCSVLoader or pywearable.loader.TesseraeParquetLoader

Published CSV layout or locally converted Parquet version of the Tesserae dataset

A loader can support samples, provider summaries, or both. Each domain function offers the finest resolution supported by the source data.

LifeSnaps [1] and Tesserae [2] are public research datasets. Cite their original publications when using them.
